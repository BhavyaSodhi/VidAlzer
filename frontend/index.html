Short Notes

1. Binary Search Tree (BST)

  • A BST is a binary tree where for every node:
    • Left subtree contains values smaller than the node.
    • Right subtree contains values greater than the node.

2. Operations

• Search, Insert, Delete

3. Traversal Methods

• Inorder, Preorder, Postorder

💡
Key Concept

Inorder traversal of a BST always yields keys in strictly sorted ascending order.

Example Code: 
1  def inorder(root):
2      if root:
3          inorder(root.left)
4          print(root.val)
5          inorder(root.right)

Topic: Binary Search Trees & Traversal
Difficulty:
Medium Q1 of 50

What is the time complexity of search operation in a balanced BST?

Correct Answer: O(log n)

In a balanced BST, tree height is strictly bounded by log2(n). Because each comparison cuts down the remaining candidates by half, lookup requires logarithmic O(log n) time.
